# My Wedding Invite (⸝⸝•ᴗ•⸝⸝)

✨ **歡迎來到我們的婚禮邀請函專案！** ✨

這是一個充滿愛與程式碼的小基地，我正在使用 React + TypeScript + Vite 打造這份獨一無二的數位邀請帖 💌

---

## 🌟 專案特色

- 🌌 **璀璨星空** - 內建 `StarBackground` 效果，讓頁面閃閃發光！
- 💻 **駭客風美學** - 特製的 `HackingTitle` 讓邀請函與眾不同～
- 🕹️ **互動小任務** - 透過 `MissionButton` 引導賓客完成冒險！
- 🎨 **精美樣式** - 使用 Styled Components & Sass 打造絲滑手感。

---

## 📂 百寶箱 (專案架構)

這裡裝了所有的秘密武器：

*   `src/components/common/` - 常用的小道具 (按鈕、輸入框、還有神奇的星空特效！)
*   `src/pages/` - 婚禮的首頁 `Home.tsx` 與閃亮亮的相簿 `Gallery.tsx`。
*   `src/features/rsvp/` - 賓客們的回覆小本本。
*   `src/assets/` - 收藏照片與風格的藏寶庫。

## 🚀 快速變身開發者 `(ง •̀_•́)ง`

想在自己的螢幕翻開這份邀請函嗎？跟著我這樣做：

### 1. 準備好工具
請確保門口已經種好了 [Node.js](https://nodejs.org/) (建議 v18 以上) 🌱

### 2. 召喚依賴
打開終端機，大喊一聲：
```bash
npm install
```

### 3. 點亮光芒 (啟動！)
讓測試環境亮起來：
```bash
npm run dev
```
然後點開控制台出現的連結 (通常是 `http://localhost:5173`)，就可以看到成果囉！ 🎈✨

---

## 🛠️ 如何點綴這份邀請

*   **想改文字內容？** 快去 `src/pages/Home.tsx` 串門子！
*   **想加新組件？** 在 `src/components/common/` 捏一個新的小組件吧！
*   **星空不夠亮？** 調整 `StarBackground.tsx` 讓星星更多更閃耀！

---

## 📦 打包出貨 `(๑•̀ㅂ•́)و✧`

當一切都準備就緒，準備要把邀請發出去時：
```bash
npm run build
```
打包後的魔法會放在 `dist/` 資料夾中，放到網路上就可以讓大家看到囉！ヽ(\*´∀`*)ﾉﾟ.:｡
